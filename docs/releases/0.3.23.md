# Pult 0.3.23

## English

- Model replies show their full Markdown, including bold text, links, lists, tables and code blocks.
- User messages longer than 500 characters start collapsed and can be expanded. The same rule applies to temporary chats and imported conversations. Copy preserves the complete original message, and search expands matching user messages.

## Русский

- Ответы модели показываются целиком с Markdown-форматированием, включая жирный текст, ссылки, списки, таблицы и блоки кода.
- Сообщения пользователя длиннее 500 символов сворачиваются с кнопкой «Развернуть». Правило действует также во временных чатах и импортированных беседах. Копируется полный исходный текст, а поиск раскрывает найденное сообщение пользователя.
