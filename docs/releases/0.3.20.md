# Пульт 0.3.20

## Русский

### Интерфейс и разговоры

- Три режима рабочего окна: «Обычный» по умолчанию, «Расширенный» и «Фокус». Сохранена палитра Пульта;
  в настройках доступны тема, шрифты интерфейса и кода, размер текста и плотность. Подсказки горячих
  клавиш перенесены в справку. Диагностика, состояние Mac и помощь — внизу слева; использование — в настройках. (#53)
- Общая кнопка «Новый чат» открывает сохраняемый разговор без проекта. Кнопка «+» проекта по-прежнему
  создаёт проектный чат. У общего разговора своя служебная папка; обычные глобальные инструкции CLI действуют. (#53)
- Субагенты открываются во вкладках с историей только для чтения и переходом к родителю. Завершённые
  можно скрыть, сохранив историю. В списке чатов — значки провайдеров и мигающая точка работы. (#53)
- Значки моделей используют цвета Пульта: терракотовый для Claude, бирюзовый для Codex и розово-лиловый для ZCode.
- Вложения показываются карточками с именем, размером и превью; технические пути отделены от видимого
  текста. Claude и Codex получают изображения нативно. Срок хранения копий выбирается в настройках:
  7, 30, 90 дней или бессрочно. (#53)

### Временные чаты

- Стрелка рядом с «Новый чат» → «Новый временный чат»: отдельный текстовый разговор без проекта,
  инструментов, вложений, MCP, пользовательских расширений и постоянной памяти. (#54)
- Сообщения и черновик остаются в памяти Пульта, вне сохраняемой истории, поиска, экспорта и локальной
  истории CLI. Закрытие окна сохраняет разговор до переподключения; «Завершить и удалить» стирает его.
  Перезапуск демона удаляет все временные разговоры.
- Поддерживается проверенная **Claude Code 2.1.317**. Codex, ZCode и другие версии CLI пока недоступны
  для временных чатов. Правила хранения данных на стороне провайдера не меняются.

### Codex, диктовка и исправления

- Вопросы Codex показываются формой с вариантами и своим ответом; черновики ответов сохраняются при
  переходе между чатом и Inbox. Поддерживаются асинхронные вопросы и уточнения текущей задачи. (#51)
- «Уточнить сейчас» добавляет сообщение без остановки хода. «Отправить сейчас» доставляет выбранную
  реплику из очереди; остальные сохраняют порядок. Очередь можно перетаскивать за ручку ≡. (#51, #52)
- Молния у Codex переключает Normal/Fast там, где выбранная модель поддерживает быстрый режим. (#53)
- Локальная диктовка через Whisper с выбором языка и микрофона. Запись не отправляется автоматически;
  модель Whisper base загружается отдельно один раз. (#49)
- Обновлены браузерные зависимости; внешний браузер Playwright запускает Chrome с включённой песочницей. (#50)
- Предупреждение о свободном месте появляется по умолчанию ниже **6 ГБ**. Порог и фраза запроса
  настраиваются в «Файлы и хранение». «Начать уборку» создаёт неотправленный черновик;
  сама кнопка ничего не удаляет и не повышает права агента. (#55)

### Обновление

Нажми кнопку обновления в Пульте или выполни `pult update`. У пакета и окна один номер — **0.3.20**.
Обновление из окна может дождаться окончания ходов. Перезапуск демона прерывает активные ходы
и удаляет временные чаты. macOS: Apple Silicon; Linux: демон и CLI.

## English

### Workspace and conversations

- Normal (default), Expanded and Focus layouts retain Pult’s palette. Appearance settings cover theme,
  interface/code fonts, text size and density. Shortcut reminders move to Help; diagnostics and Mac status
  live in the sidebar footer, usage in Settings. (#53)
- New chat starts a saved conversation without a project. Project + still creates a project chat.
  Each general conversation has its own managed working directory; ordinary global CLI instructions apply. (#53)
- Subagents open in read-only history tabs with parent navigation. Completed work can be hidden without
  deleting its history. Provider icons and a blinking dot identify conversations and active work. (#53)
- Model icons use Pult’s provider colors: terracotta for Claude, teal for Codex and rose purple for ZCode.
- Named attachment cards retain size and previews while technical paths stay out of visible message text.
  Claude and Codex receive native image inputs. Keep attachment copies for 7, 30, 90 days or indefinitely. (#53)

### Temporary chats

- New chat’s adjacent menu offers a separate text-only temporary conversation without a project, tools,
  attachments, MCP, user extensions or persistent memory. (#54)
- Messages and drafts stay in memory, outside saved history, search, export and local CLI transcripts.
  Closing the window keeps the conversation in the running daemon. End and delete removes it;
  restarting the daemon clears every temporary conversation.
- Only verified **Claude Code 2.1.317** is supported. Codex, ZCode and other CLI versions are unavailable
  for temporary chats. Provider-side retention rules are unchanged.

### Codex, dictation and fixes

- Codex questions use forms with choices and custom answers; answer drafts survive chat/Inbox navigation.
  Asynchronous questions and mid-turn clarifications are supported. (#51)
- Steer now adds a clarification without stopping the turn. Send now delivers a selected queued message;
  the remaining queue keeps its order and can be reordered with the ≡ handle. (#51, #52)
- The Codex lightning menu selects Normal/Fast where supported by the selected model. (#53)
- Local Whisper dictation supports language and microphone preferences. Recordings never send automatically;
  download Whisper base separately once. (#49)
- Updated browser dependencies; the external Playwright browser starts Chrome with its sandbox enabled. (#50)
- Low-space warnings default to below **6 GB**. Configure the threshold and cleanup prompt in Files and storage.
  Start cleanup opens an unsent draft; the button neither deletes files nor elevates agent permissions. (#55)

### Updating

Use the update button or run `pult update`. The package and macOS window share version **0.3.20**.
The window can wait for active turns. Restarting the daemon interrupts active turns and clears temporary chats.
macOS supports Apple Silicon; Linux supports the daemon and CLI.
