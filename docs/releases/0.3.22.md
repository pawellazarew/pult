# Pult 0.3.22

## English

- Browser pages keep their viewport size as the preview panel changes. A compact thumbnail expands into a large view with Fit/100% and Escape to collapse. Forms and scroll position survive; taking control remains an explicit action.
- New-chat drafts show provider skills and commands. Escape closes an empty draft and asks before discarding entered text. The sidebar leaves more space for conversations.
- The CLI panel manages the daemon and diagnostics, and opens Claude/Codex install, update and login actions. Diagnostics distinguish a failed check from a confirmed sign-out.
- Messages longer than 500 characters can be folded; composer icons are aligned consistently. Large conversation histories load in bounded pages, and file/image previews are more reliable.
- ZCode starts correctly when its app bundles provider configuration outside the standalone CLI's default search path. Explicit configuration retains priority.
- Electron is updated to 45.3.3 and the managed Node runtime to 24.22.3, including upstream security and cookie-persistence fixes.
- Packaging dependencies are patched and the arm64 app is checked after packaging, including its signature and Electron fuses.
- Recovery guards preserve uncertain Claude/ZCode input delivery so a retry or compatible rollback does not silently send it again.

The desktop release uses the Node backend. Rust remains an opt-in experimental core with an explicit private scratch home; this release does not switch the installed backend. Rust Doctor, persistent Codex memory and runtime/usage commands are development milestones, not full migration completion. Remaining native-provider, system integration, window migration and long-running acceptance work stays on the project board.

## Русский

- Размер страницы браузера сохраняется при изменении панели превью. Миниатюра раскрывается в большой просмотр с режимами «Вписать»/100%; Escape сворачивает его. Поля и прокрутка сохраняются, управление передаётся отдельной кнопкой.
- В новом чате доступны подсказки скиллов и команд провайдера. Escape закрывает пустой черновик и спрашивает перед закрытием введённого текста. В сайдбаре больше места для разговоров.
- Панель CLI управляет демоном и диагностикой, открывает установку, обновление и вход Claude/Codex. Неудачная проверка сама по себе не считается выходом из аккаунта.
- Сообщения длиннее 500 символов можно свернуть; иконки в поле ввода выровнены. Большие истории загружаются ограниченными порциями, улучшены файловые и графические превью.
- Исправлен запуск ZCode, когда приложение хранит конфигурацию провайдера вне обычного пути standalone CLI. Явные настройки сохраняют приоритет.
- Electron обновлён до 45.3.3, собственный Node Пульта — до 24.22.3: включены исправления безопасности и сохранения cookies перед выходом.
- Обновлены зависимости упаковки и проверен настоящий arm64-бандл, включая подпись и защитные настройки Electron.
- Защита восстановления сохраняет неопределённую доставку Claude/ZCode и предотвращает её незаметную повторную отправку при повторе или совместимом откате.

Этот выпуск окна работает с Node backend. Rust остаётся отдельным экспериментальным ядром с обязательной приватной scratch-папкой; установленный backend автоматически не переключается. Doctor, постоянная память Codex и команды статистики/runtime — этапы разработки. Полный перенос адаптеров, системных интеграций и окна, а также длительная приёмка остаются в плане и на доске.
