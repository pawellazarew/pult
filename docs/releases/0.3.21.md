# Pult 0.3.21

## English

- Type `/` in an existing chat to select skills and commands exposed by its provider. Claude inserts `/name`; Codex inserts `$name`. Filter by name or description and select with the mouse, arrows, Enter or Tab. Escape closes the list.
- Queue rows stay within the input width. Long messages truncate, action buttons have fixed sizes, and the subagent button aligns with the input border.
- A shared status indicator uses state colors throughout the interface. Working is blue and animated; reduced-motion settings are respected. Provider identity comes from its icon.
- Background Claude agents remain working after launch and switch to finished on a completion notification. Duplicate notifications no longer repeat completion.
- Provider icons have their own colors, and open chat menus survive interface updates.

The skill picker is available in existing chats; new-chat drafts do not show it yet. Codex terminal-only commands are not included. The design-system specification is committed; full token and component migration remains future work.

## Русский

- В существующем чате наберите `/`, чтобы выбрать скилл или команду, доступные провайдеру. Claude вставляет `/имя`, Codex — `$имя`. Поиск работает по имени и описанию; выбор — мышью, стрелками, Enter или Tab. Escape закрывает список.
- Строки очереди помещаются в ширину поля ввода. Длинный текст обрезается, кнопки действий имеют фиксированный размер, кнопка субагентов выровнена по рамке поля.
- Общий индикатор состояния используется по всему интерфейсу. Во время работы точка синяя и мигает; системная настройка уменьшения движения учитывается. Провайдера обозначает его иконка.
- Фоновые агенты Claude остаются работающими после запуска и завершаются по уведомлению. Повторное уведомление не создаёт дубликат завершения.
- Иконки провайдеров получили свои цвета; открытые меню чатов сохраняются при обновлении интерфейса.

Выбор скиллов доступен в существующих чатах; в черновике нового чата его пока нет. Команды терминального интерфейса Codex в список не входят. Спецификация дизайн-системы добавлена; полный перенос токенов и компонентов ещё предстоит.
