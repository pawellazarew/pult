# Пульт 0.3.19

## Русский

### Новое

- Новый чат открывается сразу как черновик: задача вводится до создания сессии. Черновики сохраняются
  между перезапусками окна; повтор отправки после обрыва связи не создаёт вторую сессию. (#41, #42)
- Память доступа для папок, отдельный выбор «только этот чат» и явное согласие на полный доступ. (#39, #41)
- Русский и английский для интерфейса, CLI и системных уведомлений. Язык выбирается в настройках;
  разовый запуск CLI — `PULT_LANG=en pult --help`. (#34)

### Исправления

- Вопросы Codex доступны в режиме по умолчанию. (#43)
- Просмотр исходников сохраняет расположение строк. (#35)
- Окно восстанавливает завершившиеся подписки и ошибки их создания с сохранением курсора событий. (#45)
- История читается по индексу нужной сессии и передаётся порциями, чтобы большой журнал не задерживал
  остальные запросы к демону. (#45)
- Ошибка записи журнала завершает демон с кодом 1 для восстановления через службу. Ошибка одного
  этапа уборки не отменяет остальные; общий предел ожидания остановки — 20 секунд. (#45)
- `pultd.log` ограничен 8 МиБ плюс три резервных файла. Проверка свободного места раз в минуту
  предупреждает в логе при остатке ниже 10 ГиБ. Журнал событий этим механизмом не удаляется. (#45)
- Штатная смена сетевого профиля Codex больше не считается аварийным падением. Пока у процесса есть
  фоновая работа, серверный ход или неотвеченный вопрос, смена профиля отклоняется; повтори запрос,
  когда эта работа закончится. (#45)

### Обновление

Нажми кнопку обновления в Пульте или выполни `pult update`. У пакета и окна один номер — **0.3.19**.
Перезапуск демона прерывает выполняющиеся ходы; обновление из окна может дождаться их завершения.
macOS: Apple Silicon; Linux: демон и CLI. Для проверки установки: `pult doctor --no-net`.

## English

### Added

- New chats open immediately as drafts. Write the task before creating the session; drafts survive window
  restarts, and retrying a send after a connection loss does not create a duplicate session. (#41, #42)
- Remembered folder access, a per-chat override and explicit consent for full access. (#39, #41)
- English and Russian across the window, CLI and native notifications. Choose the language in Settings,
  or override one command with `PULT_LANG=en pult --help`. (#34)

### Fixed

- Codex questions work in the default mode. (#43)
- Source previews preserve line layout. (#35)
- Ended or failed subscriptions reconnect with their saved event cursors. Session-indexed history reads
  and paged replay keep large histories from blocking other daemon requests. (#45)
- Journal write failures exit with code 1 so the installed service can recover the daemon. Cleanup continues
  after individual errors and has a 20-second overall deadline. (#45)
- Diagnostic logs rotate at 8 MiB with three backups. A disk check warns in the daemon log below 10 GiB
  of free space; event journals are not deleted by log rotation. (#45)
- Intentional Codex network changes no longer count as crashes. A profile change is rejected while background
  tasks, server turns or permission questions still need the old process; retry after they finish. (#45)

### Updating

Use the update button or run `pult update`. The package and macOS window share version **0.3.19**.
Restarting the daemon interrupts active turns; the window can wait for them to finish before updating.
macOS supports Apple Silicon; Linux supports the daemon and CLI. Check installation with `pult doctor --no-net`.
