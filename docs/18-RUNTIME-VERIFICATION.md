# Проверка превью и мобильных сред

Дата: 30.10.2026. Изменения: PR #36, ветка `feat/runtime-preview`.

## Проверено

- На втором Mac через `mac-worker`: сборка пакета и Electron, TypeScript, тесты сервиса, мобильных драйверов и UI. Полный пакет: 1636 тестов без ошибок; юнит-тесты оболочки: 132 без ошибок на проверенном снимке. На итоговом коде дополнительно прошли 33 целевых теста сервиса/мобильных драйверов/UI, 4 теста browser policy и 4 настоящих Electron-сценария, включая изоляцию повторно созданной сессии.
- Настоящий Electron: человек и агент читают одну страницу; введённое значение видно через дерево доступности; нажатие меняет ту же страницу. Проверены скрытый screenshot, размеры изображения и координаты CSS viewport, отсутствие Node/IPC Пульта на странице, блокировка привилегированных URL и popup. Подключение пустой вкладки без URL тоже проверено.
- Настоящий iOS Simulator на втором Mac: скрипт создаёт своё временное устройство, собирает UIKit-приложение, устанавливает и запускает его, читает дерево, нажимает поле, вводит текст, нажимает кнопку и подтверждает результат снимком. Чужие симуляторы не меняются; тестовый удаляется после проверки.
- Найден и повторно использован AXe из установленного Homebrew XcodeBuildMCP. Новые системные помощники для проверки не устанавливались.
- Реальный Codex CLI на основном Mac: `pult_runtime` подключился, модель вызвала discovery, attach и screenshot и прочитала строку `Verified runtime-proof` с проверенного iOS-снимка. Это проверка передачи изображения через MCP и адаптер, а не второй прогон управления устройством моделью.
- Реальный Claude CLI: `pult_runtime` сообщил `connected`. Ход модели остановлен недельным лимитом подписки до вызова screenshot. Полный визуальный прогон Claude не считается пройденным.

Второй Mac не смог определить страну выхода для настоящих провайдеров (`net.blocked`, `unknown_location`), поэтому их страж не обходился. Проверка Codex перенесена на основной Mac после успешной штатной проверки сети. Ответа `Not logged in` не было, вход в аккаунты не менялся.

## Исправления по результатам проверки

- HID-ввод AXe зависит от текущей раскладки. В реальном симуляторе ASCII превращался в кириллицу. iOS-ввод переведён на `simctl pbcopy` и фиксированный Paste shortcut, с UTF-8 через stdin.
- CDP `Network.enable` до первой загрузки страницы зависал: сначала создаётся renderer загрузкой страницы, затем включаются команды с таймаутом.
- Ручной перехват и Stop отменяют очередь и ожидающие разрешения. Проверяются поколения доступа до и после ожиданий и перед исполнением в Electron. Режим доступа берётся из снимка текущего хода.
- Внутренний переход к только что созданной сессии дожидается обновления списка. Адресная строка показывает фактический URL, не перезаписывая редактируемый адрес.
- Сетевой ответ внешнего сервиса больше не влияет на тесты с fake CLI: тестовая обвязка использует явную подмену сети. Production-страж не менялся.

## Практические ограничения

- Обновление кадров в панели — примерно раз в секунду; полноценного видеопотока H.264 пока нет.
- Android-драйвер проверен тестами с подменённым исполнителем команд. На втором Mac Android SDK/эмулятор отсутствует; реальный Android-прогон не считается пройденным.
- Android-ввод через `adb input` ограничен ASCII. iOS использует Unicode через буфер устройства.
- Автоматическая установка реализована для отсутствующего AXe с отдельным согласием. Установка Xcode, Android SDK, образов и принятие лицензий выполняются по показанным инструкциям.
- Встроенный web требует открытого окна. Физические телефоны и удалённые фермы устройств в эту поставку не входят.
- В релиз 0.3.17 функция не входит; README описывает рабочую сборку после него.

## Повторение

Обычная проверка репозитория: `./scripts/ci-check.sh`.

Проверка iOS без новых загрузок: `npm run build`, затем `node scripts/smoke-runtime-ios.mjs`. Нужны установленный Xcode, iOS runtime и AXe. Результаты сохраняются в игнорируемый `shell/test-results/runtime-ios/`.

Ключ `--providers` у iOS smoke добавляет два настоящих хода CLI и расходует квоту подписок. Применяются обычные сетевые проверки и ограничения аккаунтов.
