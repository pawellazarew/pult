# R2 — снимок и история окна

11.11.2026. Rust поддерживает `events.snapshot`, `events.history` и `events.get`.
В каталоге реализованы 10 из 86 методов. Это проверочный backend с отдельным scratch-home;
рабочая установка, реестр сессий и исполнение провайдеров ещё не переключаются.

## Данные и совместимость

`events.snapshot` возвращает `{events, activity, cursor}`. При открытии журнала строится
индекс последних `daemon.started`, `background.changed`, `context.updated`, `usage.updated`,
`limit.hit` и `net.blocked` по сессии. В памяти остаются ID и время активности, тела событий
читаются по индексу. События сортируются по ID. Активность меняют все события, кроме
`message.delta` и `context.updated`; учитывается порядок записи, а не максимум timestamp.
`session.ended` с `reason: "rm"` очищает снимок и активность старой сессии.

`events.history` читает именно `events/<session>.jsonl`, как нынешний Node-сервер.
Он не требует записи в реестре сессий. Отсутствующий файл даёт пустую страницу.
Чужие сессии, испорченные строки и не возрастающие ID пропускаются. Валидная последняя
строка без newline читается. Имя `journal` использует `_journal.jsonl`, небезопасные
имена — общий `_other.jsonl` с точной фильтрацией по UTF-16 имени сессии.

История уплотняется до разбиения на страницы: дельты склеиваются с сохранением области,
itemId и границ событий; выводы инструментов заменяются `elided`, длинный вход получает
`inputElided`. Исходные сообщения и разрешения сохраняются. Четыре недавно использованные
сжатые истории кэшируются; размер, inode и mtime файла инвалидируют кэш. Внешняя перезапись
и замена файла видны без нового события в общем журнале.

`before` — исключительная верхняя граница ID, принимается только safe integer.
`budget` принимается как safe integer и ограничивается диапазоном 1024–524288 байт.
В страницу входит хотя бы одно событие, даже если оно больше бюджета. По возможности
страница начинается с `message.user`. Ответ — `{events, more, oldest, cursor}`,
где cursor берётся из общего журнала в той же блокировке, что чтение истории.

`events.get` читает исходные события из общего журнала. Он принимает 1–200 safe integer ID
после фильтрации массива, сохраняет порядок и дубликаты, пропускает неизвестные номера.
Строки `data` ограничиваются 100000 UTF-16 units, общий бюджет — 512 KiB. Минимум одно
найденное событие возвращается и сверх этого бюджета. При остановке по размеру добавляется
`truncated: true`; cursor в этом ответе отсутствует.

Строки хранят JavaScript UTF-16, включая непарный surrogate после `.slice`. Обрезка, склейка,
JS trim и сериализация проверяются сравнением с нынешними Node-функциями. Неизвестные поля
событий сохраняются. Обработка вложенных значений использует явный стек.

Слишком большой итоговый ответ возвращает `internal` с описанием frame budget, а соединение
остаётся доступным. Историю и get выполняет blocking worker; event loop продолжает обслуживать
транспорт. Чтение/сжатие и append сериализованы блокировкой хранилища.

## Граница безопасности и восстановления

Файлы истории должны быть приватными обычными файлами без symlink/hard link. FIFO и
общедоступные файлы отвергаются явной ошибкой. Это строже Node, который возвращает пустую
историю при невозможности чтения. Данные файла и рабочего Пульта не меняются.

Автоматическая пересборка проекций из журнала отложена: нынешний контракт читает внешние
изменения файлов, включая данные, отсутствующие в общем журнале. Молчаливая замена такого
файла потеряла бы историю. Восстановление потребует явного обнаружения конфликта и проверки
при переносе реестра/импорта. Пока `projectionDegraded` сообщает об отказах текущего запуска,
а пропущенные записи среза не восстанавливаются автоматически.

## Проверка

```sh
npm ci && npm run build
node scripts/generate-rpc-catalog.mjs --check
node --import ./scripts/test-language.mjs --test dist-test/rpc-catalog.test.js dist-test/core.test.js dist-test/crash-safety.test.js dist-test/history.test.js dist-test/history-pages.test.js dist-test/history-cache.test.js
cargo fmt --manifest-path rust/Cargo.toml --check
cargo clippy --manifest-path rust/Cargo.toml --locked --all-targets -- -D warnings
cargo test --manifest-path rust/Cargo.toml --locked
```

`rust/tests/history-interop.mjs` использует настоящий TypeScript-клиент, `createStore`,
`compactHistory`, `pageHistory` и `clipEvent`. Проверяет Unicode, границы/бюджеты страниц,
удаление/повторное использование имени, перезапуск, внешнюю перезапись, обрезку полного
инструмента, опасные пути и Rust CLI. Живые модели и учётные записи не используются.
