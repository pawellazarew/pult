# R3 — чтение результата и дерева сессии

Добавлены `agent.read` и `agent.tree`, каталог содержит 15 реализованных методов из 86.
Оба читают авторитетный общий журнал и сначала проверяют наличие сессии в реестре.
Исполнение провайдеров, ожидание активного хода и текущие счётчики usage остаются следующим этапом.

## Результат сессии

`agent.read` сохраняет контракт нынешнего менеджера: `since` — конечное число, JSON-формат
возвращает события с ID строго больше курсора, а текстовый формат объединяет завершённые
сообщения, включая субагентов. Курсор продвигается по всем событиям, а не только по сообщениям.
Ответ содержит worktree, если он задан в записи сессии. История прежней сессии с тем же именем
остаётся видна, как в Node; файл проекции сессии не подменяет общий журнал.

JSON-страница учитывает канонический размер событий, включая экранирование. Первое событие
возвращается даже при превышении бюджета страницы; последующий общий лимит wire-кадра
даёт явную ошибку, если событие не помещается в ответ. Текст сокращается UTF-16 срезами до
бюджета и получает прежнее предупреждение об усечении. Пустой ответ сохраняет исходный
курсор, в том числе отрицательный или дробный.

## Дерево

Дерево строится из `agent.spawned`, `tool.called`, `agent.finished`, `tool.finished`.
Сохраняются порядок открытия, первый ID при повторе, позднее усыновление детей,
сироты, повторное закрытие, модель, тип субагента и длительность.
Пустой parentId считается заданным, неизвестные родители дают сирот.
Замкнутые циклы без корня остаются вне результата, как в нынешнем менеджере.

Построение, обход и сериализация используют индексы и явные стеки. Глубокая история
не должна переполнять стек процесса; слишком большое дерево возвращает ошибку бюджета
с сохранением соединения, если ответ об ошибке с исходным ID помещается в кадр.
Если сам ID не оставляет места даже ошибке, соединение закрывается. Длительность
использует уже поддержанную Rust-грамматику дат;
полное совпадение всех legacy-форм `Date.parse` V8 пока не заявлено. В частности,
нестроковые timestamps не преобразуются в даты, а остаются без duration.

RU/EN выбирается из locale запроса, конфигурации и системной локали. Локализация меняет
служебные подписи, содержимое сообщений остаётся исходным. CLI поддерживает `PULT_LANG`.

## CLI и проверка

```sh
pultd-rust --home /absolute/scratch agent read chat --format json --since 0
pultd-rust --home /absolute/scratch agent read chat
pultd-rust --home /absolute/scratch agent tree chat --json
pultd-rust --home /absolute/scratch agent tree chat
```

`read --format json` печатает NDJSON событий; обычный read — текст, примечание worktree
идёт в stderr. `tree --json` печатает результат целиком; обычный tree — дерево или
локализованное сообщение о пустом дереве.

`session-query-interop.mjs` сравнивает RPC и CLI с настоящими Node store/registry/manager
в отдельных временных home. Включены пагинация, усечение UTF-16, преобразование старых
значений, большие ответы, глубокие структуры, сироты и циклы, локали и повторный запуск.
Рабочий Пульт и реальные провайдеры в этих проверках не запускаются.
