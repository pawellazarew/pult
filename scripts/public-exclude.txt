# Syntax: gitignore-style globs over `git ls-files` paths, one per line. `*` stays inside one path segment,
# `**` spans segments, a pattern without `/` matches a basename anywhere, a trailing `/` means «everything under
# this directory», `!` re-includes. Last matching line wins. Blank lines and `#` comments are ignored.
